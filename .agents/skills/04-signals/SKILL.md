# 04 Signal Detection

## Purpose
Classify observed evidence into the signal taxonomy.

## Procedure
1. Read extracted evidence only.
2. Map evidence to one or more signal types.
3. Assign confidence.
4. Record interpretation limits.
5. Separate explicit pain from inferred hypotheses.

## Output
A signal list and a `primary_signal` selected only when the evidence supports one.

## Hard rules
- Job-posting age alone cannot create an `EXPLICIT_PAIN` signal.
- Funding alone cannot establish budget.
- An employee departure alone cannot establish turnover.
