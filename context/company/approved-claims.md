# Approved SynthWeb Claims

Only claims explicitly approved by an authorized SynthWeb owner may be used in outbound copy. This file is intentionally conservative until the team verifies current details.

## Approved by default

- SynthWeb provides software development services.
- SynthWeb can be evaluated for custom software development needs.
- SynthWeb can be evaluated for engineering-capacity support when the prospect's situation fits.

## Must be verified before use

- Specific technology coverage.
- Engineering Pod team size.
- Minimum engagement duration.
- Onboarding timelines.
- Pricing or cost savings.
- Availability or guaranteed start dates.
- Seniority and location of assigned engineers.
- Security, compliance, SLA, and delivery guarantees.
- Any customer logo, case study, metric, or named result.

## Disallowed without explicit evidence

- “You are struggling to hire.”
- “Your local hiring has failed.”
- “Your employee turnover is high.”
- “You have budget.”
- “You need offshore talent.”
- “We can start immediately.”
- “We are the best/only solution.”
